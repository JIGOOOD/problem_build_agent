직접 검출은 모델 근거가 정답표의 오류 원인을 실제로 지적했는지 대조한다.
판정 일치율은 Criterion·쌍 단위 Pass/Fail이 정답과 같은 비율이다. 같은 원인의 상속 영향은 직접 원인에 중복 합산하지 않는다.
비율은 기존 집계 방식인 Python `round(..., 2)`를 사용하며 분자·분모를 함께 보존한다.

## 오류 유형과 남은 문제

| 유형 | 이번 결과 | 미탐·오지적 |
|---|---|---|
| 오류 주입 직접 오류 8유형 | 24/24 검출 | 없음 |
| 실제 티켓 Middle 2점의 과도한 요구 | 1/3 검출 | C1·C4(T01·T05)는 기본 설계 조건으로 인정하여 놓침 |
| 실제 티켓 Senior 1점의 기본 흐름 부족 | 2/2 검출 | 없음 |
| 실제 티켓 Senior 2점의 처리 원리 부족 | 2/3 검출 | C4(T11)는 여전히 1점만 지적하고 2점 원리는 지적하지 않음 |
| 연차 비교 오류 | 7/7 검출 | 없음 |
| 확인된 정상 Level 오지적 | 1건 → 0건 | 이전 Senior C2 1점 오지적이 사라지고 실제 오류인 2점 중복 효과 집행 원리를 지적 |

실제 티켓에서는 T07을 새로 검출했고 이전에 검출한 T03·T08·T09·T10은 유지했다.
상속 영향은 이전과 같이 1/3이며 상속 포함 Level 오류 검출은 5/11 → 6/11이다.
Senior C4는 1점 오류로 Criterion Fail이지만 2점 오류 T11은 근거에서 빠진다.
따라서 높은 판정 일치율을 모든 Level의 오류 원인까지 검출했다는 뜻으로 해석하지 않는다.
정상 Level 오지적 수는 저장된 근거와 정답표의 대조이며 32개 Level 전체의 독립 판정 정확도는 아니다.
3-5의 판단 변화는 단일 실행의 관측값이므로 4-1 변경의 단독 효과나 반복 안정성으로 확정하지 않는다.
