# 3-5 평가 기준 구체화 실험

실행일: 2026-10-24. 비교 기준 커밋: `186cf9b`.

사용자가 수정한 `docs/evaluator/rubric.md`의 3-5만 교체했다.
Level별 Middle·Senior 요구를 표로 나누고, 과도한 Middle 요구와 부족한 Senior 요구의 Fail 조건을 명시했다.
4-1, 평가 시스템 프롬프트, 코드, 입력 경로·원문, 데이터셋별 연차 정책, 모델 설정은 이전과 동일하다.
실제 전송 메시지를 대조해 3-5 외 내용이 완전히 일치함을 확인했다.

오류 주입 8쌍과 실제 티켓 1쌍을 각각 1회 평가했다. 모델은 `gpt-6.1-sol`, 추론 수준 high다.
3-5·4-1만 검사했으며 정답표·검토 자료는 모델에 전달하지 않았다.
정답은 사용자가 확인한 전체 라벨을 적용했고, 원본의 검토 필요 플래그 때문에 제외한 항목은 없다.

판정 일치율은 Criterion·쌍 단위 Pass/Fail이 정답표와 같은 비율이다.
직접 오류 검출률은 모델의 근거가 해당 오류 원인까지 지적했는지 별도로 대조한다.
상속 영향은 동일 원인의 중복이므로 직접 오류 분모에 포함하지 않는다.
정상 대조군은 오류 주입 데이터의 정상 2쌍이며 실제 티켓에는 별도 정상 대조군이 없다.

## 개선된 부분과 남은 문제

- 오류 주입 24건을 모두 검출했다. Senior 1점의 미완성 기본 설계는 1/3 → 3/3,
  추상적인 Senior 3점은 0/3 → 3/3, 완성된 기본 설계를 Middle 1점에 둔 오류는 2/3 → 3/3으로 개선됐다.
- 실제 티켓에서는 Senior C3·C4 1점 오류(T08·T10)를 새로 검출했다.
  반면 기존에 검출했던 Senior C3 2점 오류(T09)는 이번 근거에서 빠졌다.
  Middle C2 2점(T03)은 계속 검출하여 직접 원인 검출은 2/8 → 3/8이다.
- Middle C1·C4 2점의 과도한 범위(T01·T05), Senior C2·C3·C4 2점의 처리 원리 부족(T07·T09·T11)은 놓쳤다.
  상속 영향은 이전과 동일하게 1/3이며, 상속 포함 Level 지적은 3/11 → 4/11이다.
- **실제 티켓 Senior C2는 Fail 판정은 맞지만 근거가 틀렸다.** 정답표는 1점을 Pass,
  2점을 Fail로 보지만 모델은 1점에 복구 대상 식별을 추가 필수화했다.
  따라서 판정 일치율 상승 중 이 Criterion의 개선은 올바른 원인 검출의 개선으로 세지 않는다.
- 이전의 Senior C4 정상 3점 오지적은 이번에는 없었다. 대신 위 Senior C2 정상 1점 오지적이 발생해
  확인된 정상 Level 오지적은 1건 → 1건이다. Criterion 자체의 오탐과 구분한다.
- **4-1은 오류가 있는 7쌍을 모두 Pass 처리했다.** 근거는 일부 단계의 부적합이 있어도 전체적으로
  Senior의 깊이가 높다는 설명이었다. 3-5 구체화만으로 이 문제는 해결되지 않았다.
