# 평가기 4차 튜닝 요구 범위와 기본 처리 흐름 보강

## 문제

이전 판정에서는 Middle 2점에 여러 장애·경합·부하 대응을 묶어도 상세 구현을 요구하지 않는다는 이유로 기본 설계로 인정하는 사례가 있었다. Senior 1점도 “기본 설계를 제시한다”는 표현을 그대로 인정해, 핵심 처리 대상과 결과가 연결되지 않는 경우를 놓칠 수 있었다.

## 수정

3-5에 두 Fail 조건과 정상 설계를 보호하는 경계를 추가했다.

- **Middle 2점:** 상세 구현이 없어도 여러 독립적인 경합·장애·부하 대응이나 추가 한계 분석·검증을 함께 필수화하면 과도한 범위로 판정한다. 기본 흐름에 필요한 구성요소·보장 조건이 여러 개라는 이유만으로는 Fail하지 않는다.
- **Senior 1점:** “기본 설계”라는 표현이 있어도 핵심 문제의 처리 대상·방식·결과 연결이 부족하면 Fail한다. 기본 흐름이 성립하면 상세한 경합·장애·병목 메커니즘 부족만으로는 Fail하지 않는다.

설명의 구체성뿐 아니라 **필수 요구의 범위와 핵심 처리 흐름의 완성 여부**를 함께 보도록 하기 위한 수정이다.

## 평가 결과

| 측정 항목 | 오류 주입 · 8쌍 | 실제 티켓 · 1쌍 | 튜닝 합산 · 9쌍 |
|---|---|---|---|
| 직접 오류 원인 검출률 | 100% · 24/24 | 50% · 4/8 | 87.5% · 28/32 |
| 연차 비교 오류 검출률 · 4-1 | 100% · 6/6 | 100% · 1/1 | 100% · 7/7 |
| 정상 항목 통과율 | 100% · 42/42 | 100% · 2/2 | 100% · 44/44 |
| 전체 판정 일치율 | 100% · 72/72 | 88.89% · 8/9 | 98.77% · 80/81 |

티켓에서 Middle C2·C4 2점과 Senior C3·C4 1점의 직접 오류를 검출했다. 전체 판정 일치는 80/81이지만, 실제 오류 원인을 지적한 비율은 28/32였다.

이전 차수와 티켓의 연차 정책·정답 근거가 달라, 차수 간 수치 차이를 이번 문구 수정만의 효과로 해석하지 않는다.

## 남은 문제

- 티켓 Middle C1 2점과 Senior C2·C3·C4 2점의 직접 오류 네 개는 놓쳤다.
- Senior C2는 실제 오류인 2점 대신 정상으로 제공된 1점을 지적했다. 다른 항목도 1점의 문제만 지적하고 2점의 처리 원리 부족은 빠뜨렸다.
- 정상 항목 통과율 100%는 Criterion·비교 쌍 단위다. 모든 Level의 지적이 정확했다는 뜻은 아니다.
