# 평가 기준 4차 튜닝 결과

| 측정 항목 | 오류 주입 · 8쌍 | 실제 티켓 · 1쌍 | 튜닝 합산 · 9쌍 |
|---|---|---|---|
| 직접 오류 원인 검출률 | 100% · 24/24 | 50% · 4/8 | 87.5% · 28/32 |
| 연차 비교 오류 검출률 · 4-1 | 100% · 6/6 | 100% · 1/1 | 100% · 7/7 |
| 정상 항목 통과율 | 100% · 42/42 | 100% · 2/2 | 100% · 44/44 |
| 전체 판정 일치율 | 100% · 72/72 | 88.89% · 8/9 | 98.77% · 80/81 |

정상 항목은 정답이 Pass인 Criterion·비교 쌍이다. 전체 판정 일치율은 3-5 Criterion과 4-1 비교 판정의 일치 비율이다.
직접 오류 검출은 실제 판단 근거가 정답표의 해당 Level 결함을 지적했는지 별도 대조했으며, 상속 영향은 중복 합산하지 않았다.
Criterion의 Fail 판정만 같고 지적한 오류 원인이 다르면 직접 오류 검출에 포함하지 않았다.

티켓에서는 Middle C2·C4 2점, Senior C3·C4 1점의 직접 오류 4개를 검출했다.
Middle C1 2점, Senior C2·C3·C4 2점의 직접 오류 4개는 놓쳤다. Senior C2는 정상으로 제공된 1점을 지적해 Fail했으므로 2점 오류를 검출한 것으로 세지 않았다.
