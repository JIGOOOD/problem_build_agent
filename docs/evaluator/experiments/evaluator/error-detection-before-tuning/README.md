# 평가기 기준선 오류 검출 검사

## 문제

기존 3-5는 Middle·Senior의 요구를 연차별 문단으로 설명했고, 4-1은 Senior가 더 높은 깊이를 요구하는지 포괄적으로 판단했다. 점수별로 어떤 설명이 부족하거나 과도한지 구분하는 기준이 충분히 구체적이지 않았다.

실제 판정에서는 Senior 1점의 미완성 기본 설계, 추상적인 Senior 3점, 완성된 기본 설계를 Middle 1점에 둔 오류를 놓쳤다. 연차 차이가 부족한 일곱 쌍도 모두 Pass 처리했다.

## 수정

이 단계는 수정 전 기준선이다. 평가 기준을 바꾸지 않고 오류 주입 8쌍과 실제 티켓 1쌍을 검사해, 후속 튜닝에서 비교할 오류 유형과 수치를 확인했다.

## 평가 결과

| 항목 | 연차 오류 주입 데이터 · 8쌍 | 실제 티켓 루브릭 · 1쌍 | 합산 |
|---|---|---|---|
| 직접 오류 원인 검출 | 75% · 18/24 | 25% · 2/8 | 62.50% · 20/32 |
| 연차 비교 오류 검출 · 4-1 | 0% · 0/6 | 0% · 0/1 | 0% · 0/7 |
| 정상 대조군 판정 통과율 | 100% · 18/18 | 별도 정상 대조군 없음 | 100% · 18/18 |
| 전체 판정 일치율 | 83.33% · 60/72 | 55.56% · 5/9 | 80.25% · 65/81 |

직접 오류 검출은 실제 판단 근거가 정답표의 오류 원인을 지적했는지 대조한 비율이다. 전체 판정 일치율은 Criterion·비교 쌍의 Pass/Fail이 정답과 같은 비율이며, 올바른 원인까지 찾았다는 뜻은 아니다.

## 남은 문제

- 오류 주입의 직접 오류는 18/24, 티켓은 2/8만 검출했다. 특히 Senior 1점·3점의 깊이와 Middle 1점의 점수 경계가 불안정했다.
- 연차 비교 오류는 0/7이었다. 전체적인 설명의 깊이는 인정하면서 대응 점수의 실질적인 차이 부족을 놓쳤다.
- 티켓 Senior C4는 실제 오류인 1·2점 대신 정상인 3점의 선택 근거를 지적했다. Fail 판정과 올바른 오류 원인 검출을 분리할 필요가 있었다.
