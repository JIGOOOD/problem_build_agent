판정 일치율은 Criterion·쌍 단위 Pass/Fail이 정답과 같은 비율이다.
직접 검출은 실제 근거가 정답표의 오류 원인을 지적했는지 대조하며 동일 원인의 상속 영향은 중복 집계하지 않는다.
정상 대조군은 오류 주입 데이터의 정상 2쌍이다. 다른 오류 사례 안의 정상 Criterion까지 포함하면
기대 Pass 판정은 44/44(오류 주입 42개·실제 티켓 2개)였다.

4-1에서 새로 검출한 근거는 다음과 같다.

- 02: Middle C2가 이미 Senior 수준의 복구 순서·분산 원자성·대안 비용 비교를 요구함.
- 05: Senior C3 3점의 추상적인 분석 문구에 구체적인 추가 판단이 없음을 지적함.
- 06: Middle C1이 교차 순서·비용·처리 경계 판단까지 요구하여 Senior 상위 단계와 겹침.
- 08: Middle C3가 이미 Senior 상위 단계의 공유 상한·장애 분석·상충 판단을 요구함.

놓친 03·07에서는 모델이 일부 단계의 결함과 별개로 다른 Level의 메커니즘·분석을 근거로 각 Criterion에
연차 차이가 있다고 보았다. 실제 티켓도 Senior 3점의 깊이·비용 판단을 근거로 통과시켰다.
사용자 확인 정답표 기준으로 세 쌍 모두 미탐이며, 비교할 Level의 경계를 일관되게 적용하는 문제는 남아 있다.

실제 티켓의 상속 영향은 이전과 같이 1/3이며, 상속 포함 Level 오류 검출은 4/11 → 5/11이다.
Senior C2는 Criterion Fail 자체는 맞지만 실제 결함인 2점 대신 정상 1점을 지적하므로 올바른 원인 검출로 세지 않는다.
3-5가 고정되어도 응답은 변할 수 있어 T09 재검출을 4-1 수정의 단독 효과로 확정하지 않는다.
