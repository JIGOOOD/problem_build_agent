# 평가기 2차 튜닝 연차 비교 기준 구체화

## 문제

1차에서 개별 Level의 오류 검출은 개선됐지만, 연차 차이가 부족한 일곱 쌍을 모두 Pass 처리했다. 기존 4-1의 “Senior가 더 높은 깊이를 요구한다”는 설명만으로는 같은 문제에서 어떤 추가 역량을 비교해야 하는지 분명하지 않았다.

## 수정

3-5는 유지하고 4-1의 비교 기준과 판정 방법을 구체화했다.

- **비교 축:** 처리 메커니즘·적용 조건의 기술적 깊이, 주요 문제의 원인·대응 범위, 이점·비용 또는 위험과 선택 근거를 구분했다.
- **비교 대상:** 같은 문제를 다루는 핵심 Criterion을 대응시켰다. ID가 같을 필요는 없으며 문서 전체의 길이나 전문 용어 수로 판단하지 않도록 했다.
- **Fail 조건:** 기본 흐름이 같거나 추상적인 심화 표현만 추가된 경우, 핵심 Criterion 중 하나에서 차이가 부족한 경우를 명시했다.

전체적인 인상 대신 **대응되는 문제에서 Senior가 추가로 요구하는 역량**을 근거로 판정하도록 하기 위한 수정이다.

연차 비교는 오류 주입 4/6, 실제 티켓 0/1을 검출했다. 직접 원인 검출은 오류 주입 24/24, 티켓 4/8이었다.

## 남은 문제

- 오류 주입 03·07과 실제 티켓의 연차 비교는 계속 Pass였다. 2점의 기본 흐름이 같아도 Senior 3점의 분석이나 다른 항목의 깊이로 차이를 인정했다.
- 티켓 Middle C1·C4 2점, Senior C2·C4 2점의 실제 오류를 놓쳤고, 정상인 Senior C2 1점의 오지적도 남았다.
- 3-5의 문구가 같아도 판정 근거는 변했다. 직접 오류 검출 수의 변화를 4-1 수정만의 효과로 확정하지 않는다.
