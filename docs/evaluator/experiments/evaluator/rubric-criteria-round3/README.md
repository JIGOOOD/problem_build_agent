# 평가기 3차 튜닝 점수별 비교와 상쇄 금지

## 문제

2차에서 연차 비교 오류 세 쌍을 놓쳤다. 대응되는 2점의 요구가 사실상 같아도 Senior 3점의 깊이나 다른 Criterion의 장점을 근거로 전체 비교를 Pass 처리했다.

예를 들어 오류 주입 03은 두 연차의 2점이 같은 유입 제한·대기·거절 흐름이었지만, Senior 3점의 카운터·할당 분석으로 차이가 인정됐다. 티켓도 부하 검증이나 상위 점수의 분석이 실제 유입 제어 원리의 차이 부족을 가렸다.

## 수정

4-1 판정 방법의 두 조건을 보완했다.

- **점수별 비교:** 두 연차의 2점은 처리 메커니즘·동작 조건·주요 문제 대응을, 3점은 한계 분석·Trade-off·선택 근거를 각각 비교하도록 했다.
- **상쇄 금지:** 핵심 Criterion의 비교 대상 점수에서 차이가 부족하면 Fail로 판정한다. 다른 점수나 다른 Criterion의 높은 요구로 이를 상쇄하지 못하도록 했다.

**어느 점수에서 차이가 부족한지**를 직접 판정하고, 상위 점수의 장점으로 하위 점수의 결함을 덮지 않도록 하기 위한 수정이다.

## 남은 문제

- 티켓 Middle C1·C4 2점은 범위가 넓어도 기본 설계 조건으로 인정해 놓쳤다.
- 티켓 Senior C4는 1점 부족으로 Fail이었지만, 2점의 처리 원리 부족까지 지적하지는 않았다.
- 판정 일치율 97.53%와 직접 원인 검출률 90.62%는 다른 지표다. 높은 판정 일치율이 모든 Level의 오류 검출을 뜻하지 않는다.
