# 평가기 1차 튜닝 연차 적합성 구체화

## 문제

기준선의 3-5는 연차별 요구를 포괄적으로 제시했다. 그 결과 Senior 1점이 해결 방향 제안에 머물거나, Senior 3점이 추상적인 분석 표현뿐이어도 통과시키는 사례가 있었다. Middle 1점에 이미 완성된 기본 흐름을 요구하는 오류도 일부 놓쳤다.

## 수정

`docs/evaluator/rubric.md`의 3-5를 연차·Level 0~3 표와 구체적인 Fail 조건으로 바꿨다.

- **Middle:** 1점은 문제 인식·해결 방향, 2점은 구성요소 역할·기본 흐름, 3점은 대표적인 한계·개선으로 구분했다.
- **Senior:** 1점은 동작하는 기본 흐름, 2점은 구체적 메커니즘·주요 문제 대응, 3점은 한계 분석·이점과 비용 또는 위험·선택 근거를 요구하도록 명시했다.
- 과도한 Middle 요구, 미완성 Senior 기본 설계, 기본 흐름에 머무는 Senior 2점, 추상적인 Senior 3점을 각각 Fail 조건으로 분리했다.

연차 이름이나 설명량 대신 **각 점수에서 실제로 요구해야 할 역량**을 판정하도록 하기 위한 수정이다.

오류 주입의 직접 검출은 18/24→24/24, 티켓은 2/8→3/8이었다. 3-5를 구체화한 뒤에도 연차 비교 오류 검출은 0/7로 남았다.

## 남은 문제

- 4-1은 오류가 있는 일곱 쌍을 모두 Pass 처리했다. 일부 점수의 부족을 발견해도 Senior의 다른 점수나 전체적인 깊이를 근거로 연차 차이를 인정했다.
- 티켓 Middle C1·C4 2점의 과도한 범위와 Senior C2·C3·C4 2점의 처리 원리 부족은 놓쳤다.
- 티켓 Senior C2는 실제 오류인 2점 대신 정상인 1점의 복구 대상 식별을 지적했다. Criterion 판정 일치가 올바른 원인 검출로 이어지지는 않았다.

[2차 튜닝](../rubric-criteria-round2/README.md)에서는 대응되는 핵심 항목별로 연차 차이를 판단하도록 4-1을 구체화했다.
