# 튜닝 전 평가기 오류 검출 검사

| 항목 | 연차 오류 주입 데이터 · 8쌍 | 실제 티켓 루브릭 · 1쌍 | 합산 |
|---|---|---|---|
| 직접 오류 원인 검출 | 75% · 18/24 | 25% · 2/8 | 62.50% · 20/32 |
| 연차 비교 오류 검출 · 4-1 | 0% · 0/6 | 0% · 0/1 | 0% · 0/7 |
| 정상 대조군 판정 통과율 | 100% · 18/18 | 별도 정상 대조군 없음 | 100% · 18/18 |
| 전체 판정 일치율 | 83.33% · 60/72 | 55.56% · 5/9 | 80.25% · 65/81 |

전체 판정 일치율은 정답표와 평가기의 Criterion·쌍 단위 Pass/Fail이 같은 비율이다.
직접 오류 검출률은 근거가 해당 오류 원인까지 지적했는지 별도로 대조한다.
실제 티켓의 검토 필요 직접 원인 T07·T08·T11을 포함하면서 분모가 5개에서 8개로 늘었다.
동일 원인의 상속 영향은 1/3(33.33%)이며 직접 검출률에 중복 합산하지 않는다.
티켓의 모든 Level 지적은 상속 포함 3/11(27.27%)이고, 32개 Level 전체의 독립 판정 정확도는 아니다.

## 놓친 오류와 잘못 지적한 유형

| 유형 | 오류 주입 데이터 | 실제 티켓 |
|---|---|---|
| Senior 1점에 동작하는 기본 흐름이 없음 | E03 3개 중 2개 누락 | C3·C4 1점 누락(T08·T10) |
| Senior 3점이 추상적인 분석·Trade-off 표현에 머묾 | E05 3개 모두 누락 | 해당 주입 유형 없음 |
| Middle 1점이 이미 완성된 기본 설계임 | E06 3개 중 1개 누락 | 해당 주입 유형 없음 |
| Middle 2점에 과도한 필수 범위를 요구함 | E02 3개 모두 검출 | C1·C4 누락(T01·T05), C2 검출(T03) |
| Senior 2점의 실제 처리 원리가 부족함 | E04·E07 각 3개 모두 검출 | C2·C4 누락(T07·T11), C3 검출(T09) |
| 실질적인 연차 차이가 부족한 쌍을 Pass 처리 | 오류 쌍 6개 모두 누락 | 오류 쌍 1개 누락 |

오류 주입 데이터에서 나머지 유형 E01·E08은 각각 3/3을 검출했다.
실제 티켓의 C1·C4 3점 상속 영향도 놓쳤고(T02·T06), C2 상속 영향은 검출했다(T04).
Senior C3·C4는 Criterion이 Fail이어도 모든 하위 오류를 잡은 것은 아니다.
특히 Senior C4는 정답상 오류인 1·2점 대신 정상인 3점의 선택 근거를 문제 삼았다.
이는 **정상 Level에 대한 잘못된 지적 1건**이며, Criterion 자체의 오탐과 구분한다.
이 때문에 전체 판정 일치율만으로 원인을 올바르게 검출했다고 판단할 수 없다.
