남은 문제:

- Middle C2: 2점은 '중단된 작업을 찾아 재처리'하는 기본 복구뿐 아니라 요청·결제 이벤트 중복 방지와 '불확실한 주문을 미결로 추적하여 외부 상태와 대사'하는 대응까지 요구한다. 처리 중단 복구에 중복 전달과 결제 결과 불확실성의 대응을 모두 결합해 기본 복구 흐름을 넘어선다.
- Middle C4: 2점은 자원 추가와 요청 분산, 인기 공연 내부의 분산 단위를 설명하는 데 더해 '추가 자원의 효과와 남는 병목을 부하 검증으로 확인'하도록 요구한다. 기본 확장 흐름을 넘어 잔여 한계의 식별과 검증까지 필수화하므로 중간 연차 2점의 범위가 과도하다.
- Senior C1: 1점의 '중복 점유를 막는 기본 설계와 점유 만료'만으로는 결제 결과를 어떤 좌석 소유권과 상태에 연결해 확정·해제하는지 설명하지 않아도 된다. 경합 처리의 상세함과 별개로, 평가 대상인 점유부터 결제 결과 반영까지의 기본 흐름이 필수로 보장되지 않는다.
- Senior C2: 1점은 '주문 저장과 재시도로 복구하는 기본 설계'를 요구하지만, 접수 성공 전에 무엇을 보존하고 어떤 미완료 작업을 다시 처리하는지 연결하는 조건은 명시하지 않는다. 따라서 저장·재시도 제안만으로도 충족될 수 있어 접수된 주문의 지속성과 복구를 성립시키는 기본 흐름이 부족하다.
- Senior C3: 1점은 '초과 요청의 대기나 제한 응답'을 제시하면 충족될 수 있고, 이를 어느 처리 경로에 적용해 이미 접수된 작업의 진행을 유지하는지 기본 연결을 요구하지 않는다. 이는 구체적인 병목 대응의 부족을 넘어 핵심인 유입 제어와 내부 처리 보호의 기본 흐름이 빠진 경우까지 허용한다.
- Senior C4: 1점의 '처리 자원 추가나 공연별 분산의 기본 설계'는 단일 인기 공연 내부의 요청을 추가 자원에 나누는 흐름 없이도 충족된다. 따라서 인기 공연이 하나의 고정된 처리 단위에 계속 묶이는 설계까지 허용해 핵심 확장 요구를 충족하지 못한다.
- 연차 비교: C4의 두 2점은 모두 인기 공연 내부 분산, 동일 좌석 충돌 판정 유지, 잔여 병목과 추가 자원 효과의 부하 검증을 요구하며, 상위 연차의 '확장 메커니즘'이라는 표현 외에 추가 동작 조건이 드러나지 않는다. C2의 두 2점도 성공 응답 전 진행 상태 보존·재처리·중복 방지·미결 대사로 사실상 같아, 3점의 선택 근거 추가만으로 2점의 차이 부족을 상쇄할 수 없다.

통과율은 평가기의 판정 비율이며 정답표에 대조한 정확도가 아니다. 한 쌍을 각 1회 생성·평가한 결과다.
