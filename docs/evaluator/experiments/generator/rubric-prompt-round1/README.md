# 생성기 1차 튜닝 연차 기준 보강

## 문제

기준선에서 Middle C2·C4의 2점은 기본 복구·확장 외에 독립적인 문제 대응이나 병목 분석·검증까지 요구했다. Senior C1~C4의 1점은 핵심 처리를 완성하는 기본 흐름이 빠져도 충족될 수 있었다.

## 수정

`resources/seniority-criteria.md`의 공통 규칙 7·8에 다음을 명시했다.

- **Middle 2점:** 핵심 요구사항을 충족하는 구성요소와 기본 처리 흐름, 최소 보장 조건을 요구한다. 독립적인 문제 대응이나 한계 분석·검증은 3점 또는 Senior로 구분한다.
- **Senior 1점:** 처리 대상·구성요소의 역할·처리 결과가 연결된 기본 흐름을 요구한다. 기본 설계를 제시한다는 선언만으로는 충족되지 않게 한다.

변경한 연차 기준을 주입해 Middle·Senior를 새로 생성했다. 원본 조사 자료가 없어 새로 조사했으므로, 아래 수치 차이를 기준 수정만의 효과로 볼 수는 없다.

## 남은 문제

- **Middle C4:** 3점의 “분산 효과와 취합 부담 사이의 선택”이 대표적인 한계와 개선을 넘어 이점·비용 판단까지 요구한다.
- **4-1 연차 비교:** C4의 두 연차 3점이 모두 부하 편중·조회 취합 부담과 분산 이득·비용의 판단을 요구해 실질적인 차이가 부족하다.
