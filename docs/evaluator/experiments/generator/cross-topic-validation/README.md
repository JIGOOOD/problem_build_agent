# 생성기 다른 주제 적용 검증

## 문제

티켓에서 조정한 연차별 생성 지침이 Dropbox·Slack에서도 Middle의 기본 설계와 Senior의 메커니즘·설계 판단을 구분하는지 확인했다.

## 적용

생성 프롬프트·연차 기준·평가 기준은 변경하지 않고 두 주제에 적용했다. 각 주제의 조사 자료와 선정 NFR을 재사용해 두 연차에 동일하게 전달했다.

## 평가 결과

| 평가 항목 | [Dropbox](dropbox/README.md) | [Slack](slack/README.md) | 합산 |
|---|---|---|---|
| Middle 연차 적합성 · 3-5 | 100% · 4/4 | 100% · 4/4 | 100% · 8/8 |
| Senior 연차 적합성 · 3-5 | 100% · 4/4 | 100% · 4/4 | 100% · 8/8 |
| 실질적인 연차 차이 · 4-1 | 100% · 1/1 | 100% · 1/1 | 100% · 2/2 |
| 전체 통과율 | 100% · 9/9 | 100% · 9/9 | 100% · 18/18 |

주제별 README에 실제 지적과 생성물·평가 Trace를 남겼다. 수치는 정답표 대비 정확도가 아니라 한 쌍씩 생성·평가한 결과의 통과율이다.
