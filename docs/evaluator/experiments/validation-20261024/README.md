정상 항목은 정답이 Pass인 Criterion·비교 쌍이다. 전체 판정 일치율은 3-5 Criterion과 4-1 비교 판정의 일치 비율이다.
직접 오류 검출은 실제 판단 근거가 정답표의 해당 Level 결함을 지적했는지 별도 대조했으며, 상속 영향은 중복 합산하지 않았다.
Criterion의 Fail 판정만 같고 지적한 오류 원인이 다르면 직접 오류 검출에 포함하지 않았다.

Uber는 정답이 모두 Pass이며 실제 판정은 Pass 8/9, Fail 1/9다. Senior C3 1점의 Fail은 정답 기준 오탐으로 포함했다.

Dropbox에서는 Senior C1 1점의 충돌 조정 경로 부족을 검출했다. Senior C3은 Fail 판정은 같지만 정답의 감시 연결·변경 부하 확장 경로 부족과 다른 변경 추적 연결을 지적해 직접 검출에 포함하지 않았다.
Senior C2·C4 1점은 정답상 Pass이나 Fail 처리했다. Slack은 Senior C2·C4 1점의 직접 오류를 검출했지만 나머지 4개와 4-1 오류를 놓쳤다.
Uber의 Fail은 Senior C3 1점이며 큐 보관·처리만으로 지속 보존과 재처리가 보장되지 않는다는 판단이었다. 사용자가 확인한 정상 앵커의 오탐으로 집계했다.
