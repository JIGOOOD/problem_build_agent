# 골든셋 비교 품질 평가 기준

## 평가 목적

동일한 시스템 설계 주제·범위·대상 연차의 골든셋과 Agent 생성 루브릭을 비교하여, 핵심 NFR과 중요한 설계 문제를 실제 평가 조건으로 다루는지 확인한다. 골든셋과 같은 기술·해결 방식·점수별 역량 배치를 재현하는지는 평가하지 않는다.

각 평가 기준은 Pass / Fail로 판정한다. 자료가 부족해 판단할 수 없으면 `null`과 사유를 기록하고 점수를 생성하지 않는다. 필수 입력 파일이 없거나 두 루브릭의 주제·범위·연차가 달라 비교할 수 없으면 평가 오류로 처리한다.

## 공통 비교 규칙

- 골든셋은 모범 참조 자료이지 문장 단위의 유일한 정답이 아니다. NFR 이름·번호·개수, Criterion 순서, 기술 이름과 표현이 같을 필요는 없다.
- 설계 문제와 실제 요구하는 역량을 기준으로 대응 관계를 찾는다. 하나의 Criterion이 여러 항목에 대응하거나 여러 Criterion이 하나의 항목을 나눠 다뤄도 인정한다.
- 기술적으로 타당한 다른 해결 방법도 해당 핵심 설계 문제와 품질 목표를 다루면 인정한다. 골든셋과 세부 역량·기술·개선 방식이 같을 필요는 없으며, 특정 기술의 채택 자체를 Pass 조건으로 삼지 않는다.
- 비교는 골든셋의 핵심 요구에 집중한다. 골든셋에만 있는 예시 기술이나 입력으로 확정되지 않은 수치를 무조건 필수 조건으로 강제하지 않는다.
- 생성 결과의 독립적인 기술적 타당성·중복·배점 적절성, Level 0~3의 발전과 연차 적합성은 기존 Rubric Evaluator에서 평가하고 여기서 반복하지 않는다. 골든셋의 Level 3 내용이 생성물의 Level 2에 있다는 이유만으로 Fail하지 않는다.

---

## 1. NFR별 비교

평가 단위: 골든셋의 각 핵심 NFR

### 1-1. 핵심 NFR 요구 충족 여부

- Pass: 생성 루브릭이 해당 NFR의 핵심 품질 목표와 필수 보장·개선 조건을 동일하거나 동등한 의미로 평가한다. 다른 명칭이나 여러 NFR에 나뉘어 있어도 인정한다.
- Fail: 해당 품질 목표가 빠졌거나, 명시된 핵심 보장·개선 조건이 축소되어 중요한 설계 역량을 평가할 수 없다.

골든셋 NFR과 대응되는 생성 NFR, 요구 수준의 실제 문구를 근거로 제시한다. 입력에 없는 수치가 골든셋에만 등장하면 이를 빠뜨렸다는 이유만으로 Fail하지 않는다.

---

## 2. Criterion별 비교

평가 단위: 골든셋의 각 Criterion

### 2-1. 핵심 설계 역량 포함 여부

- Pass: 생성 루브릭의 하나 이상의 Criterion이 골든셋에서 평가하는 핵심 설계 문제를 실제 평가 조건으로 다룬다. 해당 문제와 품질 목표를 충족하는 타당한 대안도 인정하며, 골든셋과 같은 해결 방식이나 세부 역량을 필수로 요구하지 않는다.
- Fail: 핵심 설계 문제를 누락하거나 단순히 NFR·기술 이름만 언급하고 해당 역량을 채점하지 않는다.

골든셋 Criterion과 대응되는 생성 Criterion을 설계 문제의 의미로 연결한다. 해결 방법이 다르면 그 대안이 같은 핵심 문제를 다루는지 실제 채점 문구로 확인한다. Fail은 해당 시스템의 어떤 중요한 설계 문제가 평가되지 않는지와 그 중요성을 설명해야 한다. 골든셋의 기술·세부 해법·점수 배치와 다르다는 지적만으로 Fail하지 않는다.

---

## 3. 평가 결과 기록 형식

각 판정에 판단 기준과 근거를 함께 기록한다.

- 평가 대상: 골든셋 NFR ID 또는 Criterion ID
- 평가 기준: `1-1`, `2-1` 중 하나와 명칭
- 대응 대상: 생성 루브릭의 NFR/ Criterion ID(여러 개 가능). 대응 항목이 없으면 없음으로 기록
- 판정: `Pass` 또는 `Fail`. 판단 불가 시 `null`로 기록하고 점수는 생성하지 않음
- 적용 기준: 해당 판정에 사용한 Pass/Fail 조건
- 판단 근거: 골든셋과 생성 결과의 관련 문구, 포함·누락된 핵심 설계 문제와 그 이유

`Pass=1`, `Fail=0`으로 변환하여 기준별 통과율을 계산한다. `null`은 분모에서 제외하고 개수를 별도 기록한다. 이 통과율은 골든셋 대비 기준 충족률이지 객관적인 정확도가 아니다.

## 기준 변경 이력

2026-10-19: `3-1` Level 동등성을 삭제하고 2-1의 타당한 대안 인정 조건을 명확히 했다. 과거의 3-1 판정은 당시 기준에 따른 기록으로 보존하며 새 기준의 통과율과 직접 비교하지 않는다. 새 결과에는 `differing_levels`와 Level 미대응 사유 `unmapped`가 없고, 판단 불가는 `insufficient_data`로 기록한다. 핵심 역량의 실제 누락은 계속 Fail이며 미대응 Criterion 수는 별도 집계한다.
